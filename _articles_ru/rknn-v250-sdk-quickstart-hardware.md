## 2. Подключение и проверка оборудования

Эта глава описывает только подключение оборудования и проверку видимости устройства, необходимые для первого запуска.

### 2.1 Список оборудования

Для запуска примеров требуется следующее оборудование:

| Оборудование | Количество | Описание |
| --- | --- | --- |
| Компьютер | 1 | Ubuntu 18.04/20.04/22.04 |
| Плата | 1 | RK3562/RK3566/RK3568/RK3576/RK3588/RV1126B |
| Кабель передачи данных | 1 | Тип зависит от платы, см. раздел 2.2 |
| Блок питания | 1 | Характеристики зависят от платы, см. раздел 2.2 |

Примечание: тип и расположение разъёма передачи данных могут отличаться между производственными партиями плат. Обычно нужный разъём помечен OTG.

### 2.3 Подключение платы

Подключение платы к компьютеру показано на примере RK3568:

1. Подготовьте компьютер с Ubuntu18.04 / Ubuntu20.04 / Ubuntu22.04.

2. Найдите на рисунке разъём питания и подключите блок питания платы.

3. Соедините плату и компьютер кабелем передачи данных. Тип и расположение разъёма могут различаться между производственными партиями. Обычно интерфейс передачи данных обозначен на плате надписью OTG.

4. Включите питание и дождитесь полной загрузки системы платы.

5. Проверить подключение платы к компьютеру

В терминале компьютера (интерфейсе командной строки) выполните следующую команду:

```text
# If adb has not been installed, please install it first using 'sudo apt install adb'
adb devices
```

При успешном подключении вывод будет следующим. 13af7b28115662cd — пример идентификатора RK3568; фактическое значение зависит от устройства. Если устройство не отображается, см. диагностику в разделе 6.1 «adb devices не показывает устройство».

```text
List of devices attached
13af7b28115662cd device
```

### 2.4 Проверка подключения устройства

Перед установкой и преобразованием модели убедитесь, что пройдены все следующие проверки:

| Проверка | Команда | Критерий успеха |
| --- | --- | --- |
| Доступность ADB | adb version | Версия adb отображается нормально |
| Видимость платы | adb devices | Плата присутствует в списке со статусом device |

После успешных проверок переходите к подготовке среды компьютера и платы.
