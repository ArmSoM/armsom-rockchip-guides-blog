# Тестирование сигнала Rockchip DP: регистры и настройка USBDP PHY RK3576/RK3588

Это полное изложение Rockchip DP Signal Test Guide V1.0.0 (RK-KF-YF-C13) для RK3576/RK3588 и Rockchip BSP с Linux 5.10/6.1. Официальная документация подтверждает RK3576 у ArmSoM [Sige5](https://docs.armsom.org/armsom-sige5) и RK3588 у [Sige7](https://docs.armsom.org/armsom-sige7). Это справочник по платформе: перед применением необходимо проверить разводку платы, экземпляр PHY, интерфейс DP/Type-C, коммит SDK/BSP, версии ядра и драйвера. Проверка на оборудовании ArmSoM не проводилась.

Предоставлен только китайский PDF (13 страниц); английская и русская версии полностью переведены с него. Отдельных технических иллюстраций в источнике нет. Все таблицы регистров восстановлены в редактируемом виде; наличие английских оригиналов рисунков не заявляется. Удалены указанные служебные заявления, контакты, целевая аудитория и история редакций; техническая версия и весь технический текст сохранены.

**Сначала проверка, затем применение:** примеры `io -4` напрямую записывают аппаратные регистры и не являются универсальной настройкой платы. В источнике есть команды без пробелов и противоречия в разрядности, смещениях и заголовках. Они сохранены для прослеживаемости. Не выполняйте спорные строки копированием; сначала прочитайте замечания ниже и сверьтесь с TRM/BSP.

## 1. Обзор DP PHY

В RK3576 и RK3588 PHY USBDP совместно используется DP и USB. Ниже рассматривается настройка сигнала при работе PHY в режиме DP. Адрес регистра равен базовому адресу выбранного PHY плюс смещение регистра.

<!-- Source PDF page 4 -->

| USBDP PHY | Базовый адрес USBDP PHY |
|---|---|
| RK3588 USBDP PHY0 | 0xfed88000 |
| RK3588 USBDP PHY1 | 0xfed98000 |
| RK3576 USBDP PHY | 0x2b018000 |

## 2. Настройка сигнала DP

Команды IO приведены для Lane0 PHY0 RK3588. Для других линий требуется изменить смещение, а для PHY1 RK3588 и PHY RK3576 — базовый адрес (здесь в источнике указано RK3756; см. замечания). Один регистр обычно управляет несколькими функциями. Перед совместной настройкой прочитайте текущее значение, примените операцию ИЛИ с новыми настраиваемыми битами согласно источнику и запишите результат, иначе предыдущие настройки будут перезаписаны.

### 2.1 Управление амплитудой DP

#### 2.1.1 Уровень основного отвода передатчика DP

При настройке напряжения источник рекомендует сначала изменять этот регистр. Смещения приведены ниже; bit5 включает настройку, значение по умолчанию — `0x0f`.

```text
lane0: 0x0810[5:0]
lane1: 0x1010[5:0]
lane2: 0x1810[5:0]
lane3: 0x2010[5:0]
```

Диапазоны и команды ниже относятся к Lane0. Например, адрес Lane1 — `0xfed89010` (`0xfed88810 + 0x800`).

#### 2.1.2 Управление током PMOS передатчика DP

Если настройки напряжения недостаточно, измените регистр тока. Биты включения — bit[1:0], значения по умолчанию — `{0x1, 0xe7}`. Диапазон настройки приведён в таблице.


## 3. Изменение параметров драйвера

Драйвер ядра: `drivers/phy/rockchip/phy-rockchip-usbdp.c`. Драйвер U-Boot: `drivers/phy/phy-rockchip-usbdp.c`. Регистры настройки swing и pre-emphasis представлены структурой:

```text
struct dp_tx_drv_ctrl {
    u32 trsv_reg0204;
    u32 trsv_reg0205;
    u32 trsv_reg0206;
    u32 trsv_reg0207;
};
```

Ниже приведены смещения регистров каждой линии. В двух последних заголовках источника повторяется `trsv_reg0206`; это сохранено и отмечено в замечаниях.

<!-- Source PDF page 12 -->

|  | trsv_reg0204 | trsv_reg0205 | trsv_reg0206 | trsv_reg0206 |
|---|---|---|---|---|
| lane0 | 0x0810 | 0x0814 | 0x0818 | 0x081C |
| lane1 | 0x1010 | 0x1014 | 0x1018 | 0x101C |
| lane2 | 0x1810 | 0x1814 | 0x1818 | 0x181C |
| lane3 | 0x2010 | 0x2014 | 0x2018 | 0x201C |

DP поддерживает четыре уровня скорости: RBR, HBR, HBR2 и HBR3. Следующие массивы задают swing и pre-emphasis. Для стандартного разъёма DP:

| HBR2 | rk3588_dp_tx_drv_ctrl_hbr2 | rk3588_dp_tx_drv_ctrl_hbr2 |
| HBR3 | rk3588_dp_tx_drv_ctrl_hbr3 | rk3588_dp_tx_drv_ctrl_hbr3 |

Для вывода через Type-C:

<!-- Source PDF page 12 -->

|  | RK3576 настройка | RK3588 настройка |
|---|---|---|

## Редакционные замечания и ограничения

В §2 источника написано `RK3756`, хотя в других местах указан RK3576. Обозначения разрядности `4'b001`, `4'b111110`, `5'b1000000` и соответствие уровней preshoot значениям регистров сохранены до проверки. В заголовках таблиц скорости фронтов указано `0x081c, bit 7:5`, а в тексте — `0x0820[5:3]`. Для частоты SSC смещение RBR указано как `0x0404`, но команды используют `0xfed88400`; старшие значения HBR3 также вызывают вопросы относительно сдвига на два бита. Не исправляйте их догадками.

Проверка изображений подтверждает отсутствие разделяющих пробелов уже в оригинале: на странице 5 — `io -4 0xfed888100x28`, на странице 8 — `io -4 0xfed888200x70`. Это дефекты источника, а не извлечения; строки сохранены, но не предлагаются как готовые команды. Запись регистров может нарушить работу DP/USB; проверяйте маски, общие биты и состояние драйвера в восстанавливаемой тестовой среде. [Подробный журнал проверки](/docs/rockchip-dp-si-test/EDITORIAL-NOTES.md).
