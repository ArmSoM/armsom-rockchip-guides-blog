Источник:двуязычный RK-SM-YF-202 V1.1. Для Android8.1+ описанного SDK;V1.1 обновлён для Android Q. Это инструкции Rockchip,не тесты ArmSoM и не подтверждение всех новых версий. Команды не выполнялись. Два снимка существуют только по одному в двуязычном PDF,с китайским UI;английских аналогов нет. Все языки сохраняют оригиналы.

## 1 Обзор

Настройка звука и анимации включения и выключения Android. Быстрый запуск см.§2.

## 2 Быстрая настройка

### 2.1 Включение и отключение

В device/rockchip/common/BoardConfig.mk измените BOOT_SHUTDOWN_ANIMATION_RINGING с false на true:файлы включаются в прошивку при сборке. false отключает упаковку.

```make
BOOT_SHUTDOWN_ANIMATION_RINGING := true
```

### 2.2 Расположение файлов

С Android7.0 анимация и звук объединены. Скопируйте анимацию со звуком в соответствующие исходные пути ниже. Выход:$OUT/odm/media/;для применения прошейте odm.img.

| Назначение | Исходный путь | Путь устройства |
| --- | --- | --- |
| Включение | device/rockchip/common/bootshutdown/bootanimation.zip | /odm/media/bootanimation.zip |
| Выключение | device/rockchip/common/bootshutdown/shutdownanimation.zip | /odm/media/shutdownanimation.zip |

### 2.3 Результат сборки

Собранные медиафайлы находятся в $OUT/odm/media/. Прошейте odm.img, чтобы применить добавленные файлы анимации и звука.

## 3 Требования к файлам

Звук включения:WAV;выключения:WAV или OGG. Изображения:PNG,глубина цвета8,размер под разрешение экрана.

### 3.1 Создание bootanimation.zip

Анимация — последовательность PNG-кадров,не один GIF. Архив bootanimation.zip использует ZIP Store без сжатия. desc.txt в ANSI задаёт размер,частоту кадров,повторы и каталоги. part0 — кадры первого этапа,part1 — второго. На снимке также есть part2,хотя пример описывает только part0/part1.

![Содержимое архива:китайский UI двуязычного источника](/docs/rockchip-android-boot-shutdown-animation/images/archive-content.png)

Содержимое архива:китайский UI двуязычного источника - Оригинальная иллюстрация;страница PDF 7 (BILINGUAL).

```text
480 427 30
p 1 0 part0
p 0 10 part1
```

Первая строка:ширина480,высота427,30кадров/с. Далее:маркер,число повторов,пауза в длительностях кадра,каталог. Источник требует p. Повторы0 — бесконечно:part0 один раз без паузы,part1 бесконечно с паузой10. При30fps кадр1/30с≈33.3мс,пауза10≈333мс. Во время пауз процесс спит,освобождая CPU для инициализации. Источник отмечает:длинная пауза может ускорить загрузку,но меняет визуальный эффект.

Подготовьте непрерывную последовательность,пакетно измените размер под экран,экспортируйте PNG с именами0000.png,0001.png и т.д. Разложите по part0/part1,настройте desc.txt. Снимок показывает нумерованные PNG.

![Последовательные PNG (не диалог ZIP)](/docs/rockchip-android-boot-shutdown-animation/images/zip-store.png)

Последовательные PNG (не диалог ZIP) - Оригинальная иллюстрация;страница PDF 9 (BILINGUAL).

В конце создайте bootanimation.zip:формат ZIP,метод Store,иначе описанная система не читает файл. После успешного создания замените анимацию. Китайский текст дополнительно требует права755;английский абзац это опускает. Требование CN сохранено,проверьте для целевого SDK.
