## 2. Подключение и проверка оборудования

Эта глава содержит только подключение оборудования и проверку видимости устройства, необходимые для первого запуска. Убедившись, что компьютер распознаёт плату через ADB, переходите к установке среды и преобразованию модели.

### 2.1 Список оборудования

Для примеров этого руководства требуется следующее оборудование:

| Оборудование | Количество |
| --- | --- |
| Компьютер Ubuntu | 1 |
| Плата RV1103/RV1103B/RV1106/RV1106B | 1 |
| Кабель передачи данных Micro USB | 1 |
| Блок питания 12V-2A | 1 |

### 2.3 Подключение платы

Подключение платы к компьютеру показано на примере RV1106:

1. Подготовьте компьютер с Ubuntu 18.04 / Ubuntu 20.04 / Ubuntu 22.04.

2. Найдите разъём питания на плате и подключите адаптер.

3. Соедините плату с компьютером кабелем данных. Тип и расположение разъёма могут различаться между производственными партиями. Обычно для кабеля данных используется разъём с маркировкой OTG.

4. Включите питание и дождитесь запуска системы платы.

### 2.4 Проверка подключения устройства

Выполните следующие команды в терминале компьютера:

```text
# Install adb if it is not already installed
sudo apt install adb

# Query ADB devices
adb devices
```

При успешном подключении вывод похож на приведённый ниже. 421ca310c9b9242b — идентификатор RV1106 в примере; фактический идентификатор зависит от платы.

```text
List of devices attached
421ca310c9b9242b device
```

Перед установкой и преобразованием модели выполните как минимум следующие проверки:

| Проверка | Команда | Ожидаемый результат |
| --- | --- | --- |
| Доступность ADB | adb version | Корректно отображается версия ADB |
| Видимость платы | adb devices | Плата присутствует в списке со статусом device |

Если adb devices не показывает устройство, см. раздел 6.1 «Устройство не распознаётся».
