Справочный материал ArmSoM по двуязычному документу RK-SM-YF-204 V1.1. Источник указывает Android 8.1 и новее, а обновление V1.1 — Android Q. Это область применения исторического SDK, а не гарантия для всех новых версий или плат ArmSoM. Проверенная плата, SoC и версия ядра не указаны. Проверьте реализацию `package_performance.xml` в конкретном Android BSP. Аппаратные измерения, тесты мощности и производительности не проводились; включение режима для отдельного приложения не является результатом измерения. Технических иллюстраций в источнике нет; код конфигурации доступен для копирования.

## 1. Обзор

Документ описывает ускорение и повышение производительности отдельных приложений, например Antutu.

## 2. Быстрое включение

### 2.1 Включение и отключение

Настройте `package_performance.xml` в `device/rockchip/rk3xxx/` и добавьте в узел имя пакета, которому нужен режим производительности. Источник предлагает следующую форму команды для получения имени пакета. `file_path.apk` — исходный заполнитель; перед применением проверьте реальный путь:

```shell
aapt dump badging (file_path.apk)
```

Источник содержит равнозначные китайский и английский шаблоны. Здесь сохранён английский оригинал; описательные значения не являются готовыми параметрами развёртывания:

```xml
<app package="the package name" mode="whether to enable the speedup, 1 means enable, 0 means disable"/>
```

В `package` указывается имя пакета приложения. `mode="1"` включает ускорение, `mode="0"` отключает его. Пример источника для Antutu:

```xml
<app package="com.antutu.ABenchMark" mode="1"/>
<app package="com.antutu.benchmark.full" mode="1"/>
```

При сборке файл включается в образ прошивки.

### 2.2 Результат сборки

После сборки файл конфигурации выводится в раздел `odm` (`$OUT/odm/etc/`). Оба языка источника требуют после добавления записать `oem.img`, чтобы конфигурация вступила в силу.

> Замечание: путь `odm` и имя `oem.img` одновременно присутствуют в обоих языках источника. Имя не заменяется молча на `odm.img`. Проверьте правила упаковки SDK и реальное соответствие разделов. Запись прошивки не выполнялась.

Официальная справка об инструментах: [Android SDK Build Tools](https://developer.android.com/tools/releases/build-tools). Она не подтверждает реализацию или эффективность режима в конкретном Rockchip BSP.
