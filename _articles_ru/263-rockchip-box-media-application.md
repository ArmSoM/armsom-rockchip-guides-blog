Справочный материал для разработчиков ArmSoM. Источник: RK-SM-YF-502 cover 2.0.1 / revision table 2.0.0. Перед применением сопоставьте SoC, Android SDK/BSP, конфигурацию ядра и инструменты с платой. Исходник не подтверждает поддержку конкретной платы ArmSoM или версии ядра. Проверка на оборудовании ArmSoM не выполнялась; примеры и снимки взяты из исходника.

## Область применения и расхождение переводов

Источник 2.0.1 — объединенная китайско-английская PDF о Box Media Center для RK с Android 7.0 и новее; ядро не указано. Один общий комплект снимков, некоторые с китайским интерфейсом, используется во всех языках; отдельного английского комплекта нет. Обложка указывает 2.0.1, таблица изменений — до 2.0.0.

**Противоречие DLNA:** китайский текст p7 требует `ro.config.low_ram = false` и `persist.sys.dlna.enable = true` для автозапуска. Английский p8 пишет `ro.config.low_ram = true`, но следующий пункт, как и китайский, запрещает автозапуск при `true`. Мы следуем китайскому `false`, сохраняя противоречие; проверьте реализацию SDK.

## 1 Обзор

Media Center — Box TV-приложение для обнаружения внутреннего хранилища, SD, USB, переносных дисков, Samba/NFS, DLNA/UPnP и других устройств; оно просматривает файлы и изображения, воспроизводит видео/музыку и устанавливает APK. Альбомные конфигурации:

- `[size:1280x720 density:160]`
- `[size:1280x720 density:213]`
- `[size:1920x1080 density:213]`
- `[size:1920x1080 density:320]`

Код зависит от платформы; его запрашивают через Rockchip Redmine/FAE.

### 1.2 Системные свойства

По китайскому условию автозапуск требует `ro.config.low_ram = false` и `persist.sys.dlna.enable = true`.

- `ro.config.low_ram`: при малой памяти `true` запрещает автозапуск; включайте через Menu → DLNA Setting.
- `persist.sys.dlna.enable`: запуск DLNA при загрузке; по умолчанию `false`.

### 2.2 DLNA

RK DLNA — многоэкранный компонент трех типов:

- **DMS (Digital Media Server):** хранит/предоставляет контент сетевым DMP и DMR.
- **DMP (Digital Media Player):** находит и получает DMS/M-DMS, воспроизводит, визуализирует и управляет.
- **DMR (Digital Media Renderer):** после настройки другим устройством воспроизводит DMS/M-DMS. В отличие от DMP, нужен DMC (Digital Media Controller) для получения контента DMS.

Для совместимости и исключения конфликтов со сторонним DLNA компонент отдельно встроен в Media Center. Включите его через DLNA или приложение-помощник. При Service Status `Opened` телефон/ПК с DLNA может передавать контент и выполнять связанные операции. При проблемах см. рисунок 9.
