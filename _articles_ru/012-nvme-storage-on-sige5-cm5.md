# NVMe на ArmSoM Sige5 и CM5: путь обновления с проверкой измерениями

![Выбор NVMe-хранилища для Sige5 и CM5](../assets/012-nvme-storage.svg)

Разъём M.2 полезен, когда производительность ограничена хранилищем. В документации ArmSoM Sige5 указана одна линия PCIe 2.1 для разъёма M-key; CM5 предоставляет расширение PCIe через плату-носитель. Это иной инженерный вариант, чем экосистема аксессуаров Raspberry Pi, и он не обеспечивает двоичную совместимость приложений Jetson Nano.

## Что меняется при миграции

Сохраните eMMC или microSD как базовый путь восстановления. Добавляйте NVMe после подтверждения надёжной загрузки платы, затем измеряйте ввод-вывод приложения, а не только результаты `fio`. На задержку влияют CPU RK3576, файловая система, тепловые условия и контроллер SSD. Тест на холодной системе без нагрузки может скрыть снижение частоты при длительной записи.

```bash
lsblk -o NAME,MODEL,SIZE,TRAN,MOUNTPOINT
sudo fio --name=read4k --filename=/mnt/nvme/test.bin --size=512M \
  --rw=randread --bs=4k --iodepth=16 --direct=1 --runtime=30 --time_based
```

Запишите версии ядра, файловую систему, модель SSD, температуру окружающей среды и источник питания. Не копируйте настройки хранилища из Raspberry Pi `config.txt`: проверьте Device Tree RK3576 и порядок загрузки по руководству платы.

## Выбор платформы для миграции

Рассмотрите Sige5, если нужна готовая плата с двумя портами Gigabit Ethernet и документированным входом 5–23 V. CM5 подходит, когда преимущества собственного носителя и набора интерфейсов оправдывают стоимость его проверки. Ни одну из плат нельзя описывать как прямую замену Jetson Nano: ПО CUDA/TensorRT требует переноса на пользовательский стек Rockchip, а подходящие модели — на RKNN.
