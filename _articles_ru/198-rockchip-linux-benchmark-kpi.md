# Показатели производительности Rockchip Linux Benchmark

Справочный материал для ArmSoM на основе китайской и английской версий RK-CS-YF-375 V1.3.0. Сохранены все технические сведения и результаты для восьми микросхем, предназначенные для сравнения при дальнейшей разработке. Это результаты Rockchip EVB, а не измерения ArmSoM или гарантия производительности других плат. Для конкретной платы ArmSoM проверьте SoC, память, накопитель, SDK/BSP, ядро, охлаждение и дисплей. Аппаратная проверка не выполнялась.

## 2. Методика испытаний

Подробно опишите методы, инструменты и настройки каждого теста для воспроизводимости. Источник переводит систему в режим производительности командой ниже. Она изменяет governor, не является операцией только чтения и здесь не выполнялась.

```sh
echo performance | tee $(find /sys/ -name *governor) /dev/null || true
```

### 2.1 Тест Glmark2

Выполните следующую команду:

```sh
/rockchip-test/gpu/gpu_test.sh
```

### 2.2 Тест UnixBench

Выполните следующую команду:

```sh
/opt/unixbench/Run
```

## Сопоставление источников

Оба источника имеют версию V1.3.0. Конфигурации восьми плат и все ячейки результатов совпадают; разбиение на страницы различается, таблица среды объединена. Обозначения GPU, включая `Valhall-G610`, сохранены без исправлений на основе предположений. Технических рисунков нет; все таблицы редактируемы. Разброс, число повторов и доверительные интервалы не указаны, и здесь они не выдумываются.

Официальные ресурсы: [Rockchip](https://www.rock-chips.com/); [документация ArmSoM](https://docs.armsom.org/).
