# Производственная прошивка Rockchip: USB, SD, программаторы и диагностика

Китайский и английский оригиналы — V1.2.3. Сохранены все способы производства, действия инструментов и диагностика. Область источника: RK3326/RK3399/RK3368/RK3288 с Linux 4.4/4.19; для RK3328 также Linux 3.10. Только справочник ArmSoM: сверяйте плату, SDK/BSP, loader, версии инструментов и память. Прошивка, стирание, переключение питания и аппаратные испытания не выполнялись.

> Прошивка, создание носителей и стирание Flash перезаписывают данные. Создайте резервную копию и проверьте цель, loader, образ и питание; не выполняйте примеры напрямую на рабочих устройствах.

Китайская версия использует китайские рисунки, EN/RU/DE — английские. Два китайских снимка ошибки подготовки IDB объединены в один английский; сохранено оформление каждого источника. Команды снимка дополнительно переписаны в копируемый текст как примеры источника.

[ArmSoM Docs](https://docs.armsom.org/) · [Rockchip tools](https://github.com/rockchip-linux/rkdeveloptool)

## 1. Способы производственной прошивки

### 1.1 Обновление по USB

1. Создайте прошивку update.img.
2. Выполните групповую прошивку FactoryTool.

### 1.2 Обновление с SD

1. Создайте update.img.
2. Подготовьте SD-карту обновления через SD_Firmware_Tool.
3. Вставьте карту и включите питание заново для прошивки.

### 1.3 Прошивка программатором

1. Создайте update.img.
2. Создайте файлы программатора через SpiImageTool.
3. Подключите микросхему памяти к программатору и прошейте её.

## 2. Работа с инструментами

### 2.1 Групповая прошивка FactoryTool

![Снимок инструмента из английского оригинала](/docs/rockchip-firmware-production/assets/en-p004-figure-01.png)

*Снимок инструмента из английского оригинала*

Порядок:
1. Нажмите Firmware и выберите прошивку.
2. При необходимости отметьте Demo и выберите образ Demo; его создание описано в OemTool ниже.
3. Нажмите Start для автоматического поиска устройств.
4. Подключите устройства; после обнаружения прошивка начнётся автоматически.

### 2.2 OemTool: создание образа Demo

![Снимок инструмента из английского оригинала](/docs/rockchip-firmware-production/assets/en-p005-figure-01.png)

*Снимок инструмента из английского оригинала*

Создание образа Demo:

1. Нажмите Select... и выберите каталог Demo.

2. Отметьте Fat32; поддерживаются только образы Fat32.

3. Задайте Disk Size больше ёмкости раздела user, с выравниванием по 100M.

4. Нажмите Start; при успехе в каталоге инструмента появится OemImage.img.

### 2.3 SD_Firmware_Tool: SD-карты обновления

![Снимок инструмента из английского оригинала](/docs/rockchip-firmware-production/assets/en-p006-figure-01.png)

*Снимок инструмента из английского оригинала*

Создание SD-карты обновления:

1. Выберите нужную SD-карту или USB-накопитель в списке.

2. Отметьте Firmware Upgrade.

3. Нажмите Select Firmware и выберите update.img.

4. Нажмите Create.

### 2.4 SpiImageTool: образы программатора

![Снимок инструмента из английского оригинала](/docs/rockchip-firmware-production/assets/en-p006-figure-02.png)

*Снимок инструмента из английского оригинала*

Создание образов программатора:

1. Нажмите Select Firmware и выберите update.img.

2. Для Emmc отметьте Reserve Data Area.

3. Заполнение пустых областей: 0 для Emmc, 0xFF для nandflash.

4. Нажмите Generate File. При успехе появятся boot0.bin и data.bin. Для Emmc нужен только data.bin; для nandflash — оба файла.

## 3. Создание прошивки обновления

### 3.1 Порядок действий

1. В каталоге исходников Android запустите mkimage.sh с аргументом ota для создания system.img, boot.img, recovery.img и других файлов. Скопируйте их в rockdev/image.

2. В AndroidTool/rockdev выполните mkupdate.bat для создания update.img; в Ubuntu — mkupdate.sh. На снимке содержимое mkupdate.bat:

![Снимок инструмента из английского оригинала](/docs/rockchip-firmware-production/assets/en-p007-figure-01.png)

*Снимок инструмента из английского оригинала*

```bat
Afptool -pack ./ Image\update.img
RKImageMaker.exe -RK31 RK3188Loader(L)_V2.10.bin Image\update.img update.img -os_type:androidos
```

Обратите внимание на -RK31: значение должно соответствовать устройству. Если оно неизвестно, откройте AndroidTool, Advanced Functions, выберите loader платформы и нажмите Download.

![Снимок инструмента из английского оригинала](/docs/rockchip-firmware-production/assets/en-p007-figure-02.png)

*Снимок инструмента из английского оригинала*

Нажмите Read Chip Info внизу. Справа появятся сведения; Image Chip Flag — нужный параметр.

## 4. Настройка программатора

### 4.1 Данные прошивки EMMC

EMMC состоит из областей USER, BOOT1 и BOOT2. Прошивается только USER файлом data.bin, созданным SpiImageTool.

### 4.2 Настройки EMMC EXT_CSD

Используйте все значения по умолчанию; настройка не требуется.

```text
EXT_CSD[167] = 0x1f（默认值）

EXT_CSD[162] = 0x0 (默认值)

EXT_CSD[177] = 0x0 (默认值)

EXT_CSD[178] = 0x0 (默认值)

EXT_CSD[179] = 0x0 (默认值)
```
