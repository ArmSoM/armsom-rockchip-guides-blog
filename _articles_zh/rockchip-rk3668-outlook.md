从边缘 AI、机器人到高性能存储和多媒体设备，新一代嵌入式平台需要同时处理计算、数据传输和复杂外设。瑞芯微 RK3668 的新一批规格信息，展示了 CPU、GPU、NPU、内存和高速接口方面的升级方向。

**ArmSoM 计划紧跟 RK3668 平台进度，在具备产品化条件后第一时间推出相关产品。** 本文先梳理现有资料中值得开发者关注的内容，区分规划参数、厂商对比数据和实际产品能力。

*依据所提供规格介绍整理的信息图，不是芯片架构图或 ArmSoM 产品实物图。原始 PPT 尚未逐页核验。*

## RK3668 主要规格一览

| 项目 | 所提供材料披露的信息 |
|---|---|
| 制程 | 6nm |
| CPU | 6× Cortex-A725＋2× Cortex-A520 |
| CPU 频率 | 大核预计最高 2.5GHz，小核预计最高 2.2GHz |
| 架构 | Armv9.2，支持 SVE2 |
| 缓存与片上存储 | 4MB L3 Cache、4MB SLC、4MB SRAM |
| GPU | Mali G2 Pro MC4，预计最高 1.1GHz |
| NPU | 44 TOPS，稀疏计算口径 |
| 内存 | LPDDR5/5X、LPDDR6；最高寻址能力标注为 64GB |
| 存储 | UFS 4.0、eMMC 5.1、SDMMC 等 |
| 视频 | 最高解码规格标注为 8K@120，编码为 8K@60 |
| 显示 | 最高配置标注为 2 路 8K@60 或 6 路 4K@60 |
| 高速扩展 | PCIe 5.0、PCIe 3.0、SATA、USB 及网络接口 |

以上是资料中的能力规划，不能直接作为某款开发板的配置表。板卡的接口引出、内存容量及功能并发组合，需要结合正式规格、硬件设计和软件支持确认。

## 六大核加两小核：先检查 64 位软件兼容性

RK3668 的 CPU 由六个 Cortex-A725 和两个 Cortex-A520 构成。材料中作为对照的 RK3588 使用四个 Cortex-A76 和四个 Cortex-A55，RK3668 调整了大、小核比例，并采用更新的架构。

迁移时尤为重要的是：**材料明确指出，RK3668 仅支持 64 位程序，不能直接运行 32 位 APK 或 ELF 程序。** 如果项目依赖旧版应用、闭源动态库或第三方算法组件，应提前确认 64 位版本。可以重新编译的代码，也需要核验依赖和运行行为。

材料同时列出了 RME、MTE、PAC、BTI 等安全相关技术。具体功能是否开放、如何配置，仍需结合后续系统和 SDK 文档评估。

## GPU 升级与虚拟化能力

GPU 配置为 Mali G2 Pro MC4，预计最高频率为 1.1GHz。材料还介绍了最多支持 16 个虚拟机的硬件辅助 GPU 虚拟化能力。

这值得安卓服务器和多实例应用开发者关注，但虚拟机数量不等于每个实例都拥有完整 GPU 性能。实际可用性还取决于驱动、虚拟化软件、资源分配和负载。

## 44 TOPS NPU，必须保留稀疏计算限定

RK3668 的 NPU 标注为 **44 TOPS Sparse**。不能脱离这一口径，将它与采用不同精度或统计方法的数字直接比较。材料另列出单核 8.8 TOPS，但未完整说明与总算力的关系，本文不据此推断内部核心数量。

支持项目包括 INT2、INT3、INT4、INT6、INT8、INT16，以及 FP4、FP6、FP8、FP16；还列出 W1.58A8、W2A8、W2A16、W4A8、W4A16 等组合，并提及三维 GRID-sample 算子、增强 MoE 支持和投机采样。

软件清单包含 Caffe、TFLite、PyTorch、ONNX NN 和 Android NN 等名称。它们代表材料中的支持方向，不意味着任意框架模型均能无修改运行。实际部署应验证模型转换、算子覆盖、量化精度、推理延迟、内存占用和持续运行功耗。目前材料不足以确认特定大模型的速度、参数规模或上下文长度。

## 内存和高速接口：关注带宽，也关注复用

材料列出的 LPDDR5/5X-8533 配置采用 4×16-bit，带宽标注为 68GB/s；LPDDR6-10667 配置采用 4×24-bit，带宽标注为 128GB/s。不同页面对 LPDDR6 的展示和计算口径存在待核对之处，这里保留资料数值，不将其写成应用实测带宽。最高 64GB 寻址能力也不代表每款板卡都配置 64GB 内存。

存储方面，材料列出 UFS 4.0 双通道，并标注 Gear5B 模式下 11.7GB/s；还包括 eMMC 5.1、SDMMC 和 SPI。上述指标不能直接等同于实际文件读写速度。

PCIe 5.0 与 PCIe 3.0 的配置均列有 x4、x2 和 x1 形式，还包括四路 SATA 3.1、双 XGMII、双 RGMII，以及多种 USB 接口。材料提到可用于多种接口组合的 PHY，但未完整给出复用限制，因此不能把全部控制器和 PHY 数量相加，作为同时可用的接口总数。

音频及其他外设包括 SAI、ASRC、PDM，以及 I2C、I3C、SPI、UART、GPIO、六路 CAN 和 DSMC。最终可用组合仍需按具体板卡确认。

## 多媒体能力与应用方向

材料列出 H.265、H.264、VP9、AV1、AVS2 等解码格式和最高 8K@120 规格；编码部分列出最高 8K@60，以及 H.264/H.265、10-bit、YUV444 等能力。不能据此认定每一种格式都支持全部最高配置。

显示方面包括多路高分辨率输出、HDMI/DP/eDP 组合接口、MIPI-DSI 和 Type-C 显示路径。图像输入部分列出双 24MP 加单 16MP ISP、HDR、降噪、MIPI CSI-2、DVP，以及拼接、鱼眼校正和图像质量处理模块。

这些能力为安卓服务器、交互大屏、NVR、CVR、显示控制、机器人、NAS、PLC、智能座舱和 BOX PC 等方向提供了评估空间。但最高规格不等于所有输入、编解码与输出功能都能同时满载运行，也不代表这些终端产品已完成认证或量产。

## 与 RK3588 的对比数据如何理解？

| 项目 | RK3668 | RK3588 |
|---|---:|---:|
| Geekbench 6 单核 | 1340 | 900 |
| GPU FP32 | 1228 GFLOPS | 512 GFLOPS |
| GFXBench MH30 | 287 帧/秒 | 144.4 帧/秒 |

这些是所提供材料中的厂商对比数据，**不是 ArmSoM 实测**。缺少完整测试平台、运行频率、软件版本和条件，不能直接转化为所有应用中的性能提升承诺。材料另有 DMIPS 图表数值，但单位与展示口径尚待原图核对，本文不据此计算提升倍数。

## 工程样片与产品上市是不同阶段

所提供规格介绍将工程样片规划为 **2027 年第一季度**。瑞芯微 2026 年第三季度报告则表述 RK3668 即将投产、RK3688 后续推出。[查看官方报告](https://static.cninfo.com.cn/finalpage/2026-10-27/1225627336.PDF)

两处材料的时间与里程碑定义尚未完全核对，不能强行合并成确定的上市日期。芯片投产、样片交付、稳定批量供货和开发板上市属于不同阶段。封装资料也尚未完整确定，因此不应以当前信息冻结量产设计。
