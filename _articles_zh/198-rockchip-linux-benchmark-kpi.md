## 2. 测试方法

详细描述所用测试方法、工具和每项设置，确保测试可复现。原稿使用下列命令将系统设置为性能模式；这会修改 governor，不是只读命令，本次未执行。

```sh
echo performance | tee $(find /sys/ -name *governor) /dev/null || true
```

### 2.1 Glmark2 测试

运行以下命令测试：

```sh
/rockchip-test/gpu/gpu_test.sh
```

### 2.2 UnixBench 测试

运行以下命令测试：

```sh
/opt/unixbench/Run
```
