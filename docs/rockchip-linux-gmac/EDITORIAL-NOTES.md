- Linux 3.10 驱动路径写作 `driver/net/ethernet/rockchip/gmac/*`，疑缺 s；保留原值。
- Jumbo Frame 描述 MTU 9000，示例使用 `ping -s 9000` 并输出 9028 字节。不能将示例解释为已验证无分片或特定 MTU 下的标准测试；保留原日志。
- 中文写“Junbro Frame”，英文写“Jumbo Frame”；中文原正文信息保留，标题用通常名称。
- Link 段“将 MDC/MDIO 与主控断开，与电脑直连”表述有歧义。不能照字面把 MDC/MDIO 管脚连接 PC 网口；需根据板级原理图确认测试接法。
