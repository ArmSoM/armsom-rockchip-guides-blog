2. RK3288的5.3 vopl示例最后为 `}` 而不是 `};`，中英文均原样保留。文章不是已经编译验证的DTS。
3. 第2章关于理想差分放大器 `U_a = U_b` 和隔直流的表述按原稿保留，未当作实测结论或自行重写电路理论。
4. 前言产品版本表没有列RK3562，而平台支持表包含RK3562；保留这一区别。文档没有证明全部板卡实际引出LVDS。
