## 关键核对与限制

- 目标芯片为 RK1820、RK1828、RK3572。RK3588/RK3576 片内 NPU 与 Toolkit2 的路线分开；ArmSoM 产品只作为候选主机参考，没有声称 RK182X 即插即用或已完成硬件适配。
- Toolkit Python 使用 `from rknn.api import RKNN`；不得根据 SDK 名称杜撰 `rknn3.api`。未安装或运行厂商 SDK。
- macOS Toolkit 的离线转换支持与 PC-host Runtime/proxy 的 USB 通信属于不同组件，不能把其中一项支持范围套到全部工具。
- Toolkit Lite 异步任务提交不等于计算完成，不编造等待函数签名；精确缓冲区及等待契约以对应手册为准。
- C Runtime 的 context、模型载入、模型初始化与资源释放分开描述。文中名称用于说明职责，不冒充可直接编译的完整程序。
- RKLLM3 Server 的 OpenAI-compatible 接口只表示文档所列范围，不等于全部接口完全一致；健康、模型列表与真实推理分别验证。
- 算子支持还取决于目标平台、类型、形状和属性。Python 示例只统计图节点，不声称自动判定兼容性。
- MoE 适配章节使用 `rknn::exUnifiedMoE` 表示 routed experts，shared expert 和合并位于节点外；当前 B=1，权重布局 [in,out]。
- MoE 英文稿 §3.2 一面标记 `enable_moe_tc` 未实现/不支持，随后又说明启用方法。文章保留冲突并按不可用处理，初始评估保持默认禁用，不承诺该能力已交付。
- MCP 文档中的服务器/本地 Agent 角色区别不等于整个客户端流程无数据传输。未连接该 MCP 服务，未配置账户、密钥、上传模型或授予设备权限。
- 四语代码块和接口标识符保持一致；正文为自然本地化。部分系统支持范围只提示按原文选择，没有推导未披露的版本组合。
