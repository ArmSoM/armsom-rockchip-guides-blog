## 原文疑点（保留原值）

1. §1.1 流能力表最大高度写 4096、2560、1920，而 §4.7.1 为 2160、1440、1080。已对照源图确认并非 OCR 错误，不擅自统一。
2. §4.7.2 的 2K 与 1080p 示例文字分别说明 297MHz、148.5MHz，但公式分子仍印 594；结果却为 2.23 与 1.12。保留公式并在正文说明矛盾，待原厂确认。
3. §2.1.3 force-hpd 上下文中引用 dp0 与当前接口可能不符；必须按目标节点配置，不把举例当全部板卡实际配置。
4. 表中 Display Split Mode 与正文“单接口分屏”语义范围不同，不能据此断言所有模式均受支持。
5. Steam、HDP、DPCP、preocess、vatctive 等拼写及 misc1 说明中写 misc0 等问题按原文可追溯保留或在译文明确说明；旧交叉引用不能作为新版章节定位的唯一依据。
6. 固定地址读写、PHY 调参、强制输出、HDCP 测试均是原文示例；必须结合目标 SoC TRM、原理图、内核和 BSP 核验后执行。
