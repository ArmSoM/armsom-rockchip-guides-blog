## 原文疑点与待核对项

1. 第 13 页 I2C 图正文引用 Table 5-1，标题却写 Table 5-2；表中 `IO_GPIO3b3` 对应 `GPIO3B_OE[2]`。全部按图保留，实际硬件映射需核对芯片手册。典型地址 `7’b1010000` 与示例地址 `0x51` 属于不同配置，不擅自统一。
2. 第 21–22 页 ISP 说明涉及 650M、`RK628_CSI_PIXEL_RATE_HIGH` 的 600000000 及驱动增加 25% 等上下文；不能由文章推定目标板卡安全超频上限，须核对实际驱动及供电/时序。
3. EDID 数组含原文省略号；保留原样，不补成完整 EDID 二进制。
4. 第 25 页 `setenforce 0`、第 32 页将设备节点改为 `0666` 是原文调试示例，会降低访问控制；不作为生产安全配置建议，需独立安全评估。
5. 原文命令说明中的 `demsg` 拼写保留并在译文提示，应结合实际环境核对 `dmesg`。
6. 第 31 页日志原图部分行前缀和 `/i2c@...` 右端已被截断，未猜补。第 21 页 XML 截图右侧注释被截断，转录保留可见完整 XML 元素，不捏造注释尾部。
7. Git hash 为原文快照，不能保证其他 SDK 分支相同；截图所列提交不是本次仓库提交。
8. 未取得真实板卡、SDK/BSP 和接线，所有引脚、电压、频率、寄存器及路径仍须按目标板卡验证。原图日志不是 ArmSoM 实测。
