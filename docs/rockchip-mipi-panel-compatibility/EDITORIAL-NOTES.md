## 原稿疑点（不擅改）

1. PDF 第10页及另一 DSI2 fixup 对应代码使用 `fdt_setprop_string(..., "status", "disa")`，第8页流程/第22页示例则为 `"disabled"`。已视觉核对第10页确认不是提取截断。保留原代码并在三语开头提示。
2. 第21页补丁最后停在 `rockchip_panel_prepare` 的上下文 `if (!panel)`，原稿未给更多上下文，也没有完整补丁尾部。不得据文章宣称该补丁可直接 `git apply`。未编译、未应用、未硬件验证。
3. 第5–7页的两个候选 panel 均为 `@0`/`reg = <0>` 且初始 `status = "okay"`；这是动态候选筛选示例，保留原值，不修改为独立显示链路。
4. ID 属性示例使用寄存器 `0xdb`、值 `[10]`/`[72]`，日志示例使用 `0xDA` 与 `09`，并列是原文示例，不将不同面板的值强行统一。
5. PDF 抽取的 diff 存在分页排版空行及上下文缩进重排；所有补丁行/符号保留，但不保证形成可直接应用的补丁文件。工程应用必须对照相应 SDK 原始提交。
