## 原稿疑点与风险（已进入四语正文）

- H256疑似编码名笔误，原样可追溯保留，不猜改成另一编码名。
- 周期占比95%或更高与本文引用USB2.0的80%上限不同，可能破坏非周期设备，不适用于xHCI；保留原例及风险，不作为通用建议。
- uvc-data.py假设固定文本格式，直接访问line[0]/line[1]，未检查空行/短行或十六进制转换错误；eof跨行状态及末帧保存需真实数据核验，未更改算法。
- 固定高频/关闭IDLE/autosuspend增大功耗热负担，bind/unbind中断设备服务，正文已警示。
- 所有测试、日志和性能数据属于原稿，非ArmSoM实测；具体板卡、SDK/BSP、内核和摄像头未验证，没有执行硬件命令。
