## 修正与明确保留的疑点

- 修正 PDF 提取的断行、分散表格、列表与单位排版，恢复可编辑 Markdown 表格。截图仅作为对应电路、框图与时序图；照片/图纸没有伪造板级实测结论。
- RK3572 V1.1：Vulkan 1.4、LPDDR4/4X 在两个 rank 时不支持 R17、VideoPort1 2048×1080@60/8-bit；沿用旧 URL，避免产生同主题重复页。
- PCIe/SATA：数据手册的两组 PCIe/SATA/USB 加一组 PCIe/SATA 是三组复用 PHY；设计指南明确两个 PCIe 控制器、两个 SATA 控制器。不同资源统计口径不能误写为三个独立端口。此项经过复核，未把它保留成未经证实的“版本冲突”。
- 显示：datasheet VideoPort1 2048×1080@60 与指南双屏示例中第二路 2560×1600@60 不一致，正文明确提示，未承诺后一组合可用。
- eDP：电路章节 100 nF 与 PCB 章节 220 nF 耦合电容建议不一致，正文同时保留，待原厂/面板规格确认。
- USB ESD：电路章节 3 pF/0.25 pF 与 PCB 章节 1 pF/0.2 pF 的建议不同；文章采用更严格后者，并注明仍需验证器件与链路。
- Reset：100 个 24 MHz 周期约 4.17 µs，原文约称 4 µs；以周期要求及设计裕量为准，与最后电源稳定后的 ≥1 ms 保持时间分开。
- DDRBIN：ADC 416 对应 Config 2，不能写成 `adc_value_to_ddr_config=416`；多档配置应以前一次修改后的 binary 为下一次输入。独立说明的页眉误写 RK3588 不作为平台依据。
- RK730：Pin 2/17 与 9 为 NC；PVDD/HPVDD 描述更新；24 MHz PLL 输入改为 MCLK；HK_TOP_2 复位值 0x20、DAC 编码 11 为 −1.4 dB、LSB_RX/TX 的 0=MSB/1=LSB 同步说明。
- RK730 原文仍有 PLL 2.822 MHz、SCL 方向 O、SPI 说明缺少完整引脚映射等疑点，明确标注，不猜测硬件接线。
- RK730 六组启动/关闭序列保留原始位赋值及顺序；未运行寄存器写入或板端命令。
