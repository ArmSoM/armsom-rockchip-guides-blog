## 待核对的原文问题

1. 产品表 RK3399 Main-Link rate 为 2.7/1.62Gbps，但 §6.1 带宽示例结论声称 RK3399 可支持每 lane 4.46Gbps，矛盾未擅自消除。
2. 寄存器基址表 RK3399 与 RK3288 的控制器/PHY 地址相同；必须查目标 TRM/BSP，不据此执行寄存器写入。
3. §4.1.3 Panel delay 的文字释义必须结合实际 binding 与面板规格确认，不能仅凭示例值部署。
4. force-hpd、T3 超时及降低等待时间等属于源文的具体排障建议，不代表所有面板都可使用该时序。
5. 强制输出属于可能违反链路正常训练流程的调试方式；保留原文风险提示，不宣传为量产通用方案。
6. 源代码补丁中的空白、hunk 数量和目标版本需要在对应 BSP 中再校验；这里完整保留展示代码，不声称补丁可直接 git apply。
