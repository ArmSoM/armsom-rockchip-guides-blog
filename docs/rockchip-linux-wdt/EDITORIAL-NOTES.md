## 原稿疑点（不猜改）

1. 中文p7 RK3506两行devmem地址为`0x0xff288028`，而io为`0xff288028`。已查看原页确认非提取错误，正文四语提示先核TRM/BSP，表内原值保留。
2. RK3588暂停值`0x00010001`与恢复值`0x00100000`写掩码不对称，中英原稿一致如此。不得根据文章直接写寄存器，须按实际实现核实。
3. 原文100MHz最大超时计算写21秒，数学结果约21.47秒；保留原式并说明近似，不擅改示例。
4. close/V/CONFIG_WATCHDOG_NOWAYOUT行为是文档描述，需实际驱动和内核确认；不得外推所有ArmSoM板卡。
