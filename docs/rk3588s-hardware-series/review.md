## 逐项差异与疑点

- §2.1.2：100 个 24MHz 周期与约 4μs 并列；按计算约 4.167μs，不将 4.000μs 当合格。
- p40：eMMC 正文引用表 2-6，但实际表号 2-5。按实际表号整理。
- p42：FSPI 列 M0/M2，却提三个电源域，启动说明还出现 M1。不推导第三接口，要求按 TRM、启动固件核对。
- p48、61–62：部分电源网络名称/峰值文字不一致，保留需核对事项，不重命名电源或猜测电压。
- p90、221：USB3 ESD ≤0.3pF 与 ≤0.2pF 两处不同；并列记录，以严格预算建议审查，不声称器件已认证。
- p94–95：PCIe 明确为两个 PCIe2.0 x1 RC，仍有 PCIe3.0 遗留文字；“不能同时使用”范围不清，未承诺两端口并发。
- p100：Combo DPHY 不支持 skew calibration，优先 1/2 Lane；4 Lane 的 T_lane0≥T_lane1≥T_lane2≥T_lane3 原样保留。
- p100：Combo RX 正文写 DPHY V1.2/2.5Gbps，图 2-103 内却写 V2.0/4.5Gbps。专题明确列出的 2.5Gbps 只用于专用 DPHY，不从图中推导 Combo RX 的最终可用速率，项目需按芯片规格和厂商确认。
- p108/220 与 p114：HDMI 偏置 590Ω 和 499Ω 冲突，四语并列保留，BOM 前需厂商确认。
- p107、115、120：TX1/TYPEC1 等残留命名不用于推导第二组接口。
- p218：PCB 仍有 HDMI RX 布线章节，与 S 系统接口框图不一致。本系列没有由此新增 HDMI RX 文章或宣称 S 支持 RX。
- p133：ETH0 残留文字不代表第二个 GMAC；按 GMAC1 与 VCCIO5 整理。
- p81：SARADC 12bit 与 ±35 键值/123mV 描述的尺度不清，不自行换算。
- p147：8 层 HDI 文字把底层写 L9；提醒按叠层图与板厂核对，不复制成层定义。
- p162/163：图 3-30 重号；p215 图 3-111 重号。图片按物理页码命名，不依赖图号唯一性。
- p178：BIG PDN 为 0.025/0.04/0.14Ω，不能沿用 RK3588 的数值。
- p215–217：DDR 表按 RK3588S 10 层 HDI，DQ/DM 45Ω、地址控制 50Ω、差分 90Ω。没有引入其他指南的 8 层 PTH/16ps 规则。
- p229：θJA/θJB/θJC=8.2/3.7/0.01°C/W 为指定 FEM 模型，200×140mm、1.6mm、10 层、无散热片；不是 ArmSoM 实测。
- p241：MSL1 的 300℃疑似错误，不作为工艺条件；MSL3 与限厚烘烤表分开说明。

## 产品适用与未验证项

官方产品资料核对 CM7S 与 Sige7S 的 RK3588S 定位，文章链接产品页与官方文档。使用仓库既有 CM7s/Sige7s 产品标识，不增入口。模块内部电源/DDR/启动电路与载板分工分开。未做硬件、BSP、内核、热设计、SI 或 EMC 认证测试。所有最大值和参考电路不能推导成产品全部引脚能力。RK3588S2 不当作无条件直接替代。
