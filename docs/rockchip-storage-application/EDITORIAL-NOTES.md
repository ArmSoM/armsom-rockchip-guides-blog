## 已识别的版本差异与疑点

以下均已在四语正文前部直接说明，读者无需打开本记录才能看到关键差异。

1. §2.3：中文 SPI NOR 封装 `5x4 SOP8/8x6 WSON`，英文仅 `5x4 SOP8`。采用中文较全写法。
2. §2.8：英文补充 SLC NAND / Nand V6 为 `16 bits per 1KB`；中文表为 `16bits ECC`，中文 §3.1 本身也提到 `16bits/1KB`。
3. §4.1 启动支持表：RK2108 SD Boot 中文 N / 英文 Y；RK3328、RK3399 EMMC/NAND 中文 Y/N / 英文 N/Y；RK3399 SPI NAND 中文 Y*1 / 英文 Y；中文 RK3229 行在英文名为 RK3228。采用中文值同时并列记录英文冲突，不猜测哪一版真实，不认证任何板卡能力。
4. §4.2：英文 RK3568/RK3566 的 USB1 明确 `3.0 OTG (RK3568 Only)`，中文仅 `3.0 OTG`。英文限制作为补充保留；该表跨页不同，比较时按芯片行配对，而非误认为页数差就是数据新增。
5. §4.3 两稿均写 `EMMC--`，照录待核对。
6. 英文第 9 页额外强调 RK 逐步淘汰 PP NAND、Flash 主要转 SPI Flash，已作为历史平台背景补入，非当前全部 ArmSoM 产品承诺。中文自身也有相关背景，但不静默丢弃英文独立段落。
7. 英文第 36–37 页在 SPL 后额外放置 Loader 两图，与后文重复；保留但明确不能根据位置推断为 SPL 独立流程。
8. §7.2 表 `drivers/rkand` 与后文 `./drivers/rk_nand/` 不一致；保留待核对。
9. API 名 `vendor_storage_read` / `rk_vendor_write`、示例类型 `uint8` / `uint32`、宏 `ERROR`、格式字符串 `% s` / `% x` 原稿已有；没有擅自纠正或补齐源代码。读写示例未关闭 fd，未认证可编译性；写入 SN ID 1 具破坏风险。
10. §6.1.4–6.1.5 两稿都写 Linux 类似 Android 工具，未擅改成 Windows；`RB_CHECK_OFF` 原文“回读调用”措辞不清，未猜测标志极性。
11. RK partition 模板的注释类型值和实例 Type 值不是本文擅改的；保留原稿，需与实际 SDK 格式核对。
12. 原稿价格为历史示例，未查询或承诺现价。烘烤、30K/100K P/E、7 天掉电等数据是原文描述，非 ArmSoM 实测。
