## 原稿疑点：保留原文，使用前核对 SDK

以下不作为已修复的技术结论；正文保留可追溯原始信息。

- 第 1 章图题 ISP21 与 ISP30 主体不一致；正文又出现 ISP21、RK356X、RV1106、AWBV32 等其他代际/型号，不能据此扩大板卡适用范围。
- §5.1.6 与 §5.1.7 同名 `rk_aiq_uapi2_camgroup_getOverlapMap`，保留两节；`Carmelaghrup`、`parsmout`、`librkaiq.sov`、`OP_MANUALl` 等源拼写不擅改。
- AE 线性/HDR 曝光时间说明存在毫秒/秒混用；直方图声称五种模式却列 Y/R/G/B 四项；手动曝光列三项开关却称四项。
- 15×15 权重说明的 AdvancedV2_t/Advanced_t 类型不一致；多节点 AecRoute 说明却称第二节点最大；HDR FRM0–3 与三元素数组不一致。
- EvBias 公式字面上除以 `abs(EvBias)`，零值行为未解释；示例数值与注释如 `.002f` / `.02` 不一致。均不猜测修正。
- 光圈 DC/P-iris、`DCIrisHoldValue` / `DCIrisValue`、Open/Close PWM 区间及表号引用存在矛盾；WinB 约束引用 WinA 偏移，保留源文。
- `V2IIR1x3` / `V13X3`、`shitbit` 等原始类型/拼写，以及 RAW merge 中不完整句子不擅补技术条件。
- p319 的 SlopeAtZero 范围含负号，p322 原图却明确写 `0.05 and 0.05`；已重新渲染 p322 核对，不是提取漏负号。`GammaBeef` / `GammaCoef` 不一致；p329 获取矩阵名 API 的说明却称获取 saturation，p338 get 模式说明却称 set，p348–349 LDCH 说明称 FEC，p373 `PADF` 拼写均保留待核。
- p200–300：`Hillitt` / `Optmod` / `Dirk_Optmod_Hillit` 疑似错拼；单元 2478 条件写“为 5”却给 0/1 范围；单元 2536 未说明 UV 比例增减方向；2666 使用 `enhance_setting` 却称 Dehaze 开关；2759、2901 默认值缺失；2825 范围原写 `0,2 to 0.016`；2862 精度 0.1 大于所列 [0.002,0.01] 范围。
- 日志例 `0x4ff4` 被称 debug，但低四位 4 对应同页 verbose；API/驱动版本匹配示例 0x30/0x40 含混；AWS/AWB、Mrerge 保留原写法。
- AIR 最小范围 [230,250] 却默认 200；白点 RG/RB 描述有不一致；RKRAWV2 推荐块说明重复称 Raw Blocks。不得据此替换常量或猜测块名。
- RKRAWV2 寄存器格式表的 Frame number 说明写成“寄存器基地址”；帧统计表 `HDR_Gain_M_REG`、`HDR_Gain_S_REG` 的原图描述写“快门寄存器”，与 Gain 字段名矛盾。恢复表保留原说明并明确待核对，而不是静默改成增益寄存器。
