## 原文疑点：保持原值，需厂商/BSP 核对

| 位置 | 问题与处理 |
|---|---|
| p.6、p.14 | 功能列表写 DSI-2 Version 1.1，Eotp 说明写 RK3588/RK3576 DSI V2.0；保留两处，不擅自解释为同一版本。 |
| p.11–13 | 属性表写 `auto-calculation`，DTS 示例写 `auto-calculation-mode`；保留。若干布尔项写“布尔类型 string”，保留并在译文标注原文措辞，不猜为合法 DT 类型。 |
| p.19 | C-PHY 代入公式使用 4450，而同图 Htotal=4400；C-PHY 左侧公式单位 Gsps，右侧数值单位 Gbps。均按原图记录，不把结果视为修正计算或实测。 |
| p.21、p.23 | DSC 波形/带宽及客户屏参数只按源文记载，不用其推出所有面板均可按固定 1/3 带宽工作。 |
| p.35 | 原文 `tree-wire-trios` 疑为 `three-wire trios`；译文给出三线含义并保留原拼写说明。 |
| p.52 | `mipi_pixel_clock = cds_clk/2` 的 `cds_clk` 与其他 DSC 时钟名称可能不一致，保持原拼写。 |
| p.60–69 | 补丁为文档示例，未验证可直接应用。`REG_645M_MASK` 为 GENMASK(2, 0)，读取却 `>> 4`；cap_peaking 的掩码/移位亦需核对；保留原值，不修算法。 |
| p.71–73 | 正文电阻编码前半为 43/46/49/52/56/60/66/73Ω；p.73 设置图为 42/44/46/49/52/58/64/73Ω。分别保留并在三语图表旁提示，不选择其一覆盖。 |
| p.73 | 寄存器默认 `EDGE_CON_DIR` 与设置指南、补丁中依 DPHY/CPHY 选择方向的写法需按实际芯片/BSP核对。寄存器表保留原图默认值。 |
