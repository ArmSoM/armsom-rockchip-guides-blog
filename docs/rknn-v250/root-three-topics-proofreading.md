## 原稿疑点与适用限制

- RV1103/RV1106 使用 Mini Runtime `librknnmrt.so`，不能替换为通用 `librknnrt.so`。没有确认相应 ArmSoM 板卡，明确标为平台参考。
- 通用入门包含 Rockchip EVB 图、供电和 USB 示例。ArmSoM 板卡即使使用同 SoC，也须按本板 BSP/接口/电源要求适配；未宣称这些 EVB 步骤为 ArmSoM 实测。
- 原稿的旧驱动日志、旧 Runtime/Toolkit 版本输出是示例，不能视为 V2.5.0 验证结果。正文保留原始数值和具体推荐版本；没有修改原稿常量。
- 通用快速入门第 6 章引用开发指南“第 10 章 FAQ”，而新版开发指南的实际章节编排需结合该文目录查找；保留原文引用并在此记录，未伪造锚点。安装失败引用“5.4.2”同样以实际新版指南目录为准。
- pip/latest/未固定仓库版本的安装命令不保证取得 V2.5.0。示例沿用原文，实际操作须匹配完整 SDK、Runtime 与驱动版本。
- Lite2 加密说明列出的芯片范围比安装支持表更广。两处均保留，四语适用说明明确不能据此扩展 Lite2 Python 支持平台。
- Lite2 `reuse_outputs=True` 返回内部缓冲视图，下次 inference()/get_outputs() 会覆盖，完整保留复制结果的要求。core_mask 的 RK3576/RK3588 限制和 RK3588 专属组合均保留。
- 表格里的 shell 管道以 HTML 字符实体显示 `|`，防止 Markdown 分列，不改变可见命令。
