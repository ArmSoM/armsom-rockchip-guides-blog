## 保留的原文疑点（未擅改）

- §1.1 出现 `GRM/PMUGRF`，与后文 `GRF` 术语不一致；原文保留。
- p.9 DTS 例存在 `rockchip,pin` 单数形式，其他例使用 `rockchip,pins`；不全局替换属性名。
- p.10 `gpio2a0_ds` 表复位值 `0x6`，但可见驱动强度映射只列 `3'b000` 至 `3'b101`；原值和映射完整保留，不猜测缺失编码。
- p.15 前文说 RK3588 Android12，代码注释涉及 Android14；保留并要求实际 SDK 复核。
- §8.1.1 p.30 原文称写 bit0，但该处未给对应实际写命令；未自行补造。
- §8.1.2 p.34 文字说写 `0x1234`，命令却写 `0xffff1234` 并有高 16 位 mask 注释，输出也为 `ffff1234`。全部照录，不能把任一数值当作通用硬件结论。
- §9.3 讨论 GPIO4，但时钟状态命令示例出现 gpio3；未替换。
- §9.5 有“IO复位”表述，且 GPIO2C2 文字与图中 GPIO1_A5/A6/A7 示例不一致；分别保留。
- §10.4 标题写 RV1108 `gpio1a0~gpio1b1`，正文写 `gpio3b0~gpio3c3`，原文冲突保留。
- §10.8 为原文中断绑定补丁，不代表当前所有 SDK 的 API 或行为；未应用补丁。

## ArmSoM 适用和安全

源适用表为“Rockchip所有平台”，并不等于所有 ArmSoM 板卡支持所有例子。具体例涉及 RK3399、RK3588、RV1103/RV1106、RV1108；内核/U-Boot、Android、SDK/BSP、引脚、电压域及外设接线必须按实际板卡核实。无硬件实测。文中 IO 域设置、GPIO 输出、时钟操作、寄存器写入与休眠操作可能影响系统或损伤硬件，均未执行。
