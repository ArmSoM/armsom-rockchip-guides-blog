## 原文疑点与适配边界

1. 中英文 §4.2.7 均将 `SYS_STATUS_DUALVIEW` 写了两遍，§4.2.8 则是 `SYS_STATUS_DUALVIEW` 与 `SYS_STATUS_ISP`。不猜改源条件；俄文明确指出矛盾，实机适配需核对 DMC 驱动。
2. 中英文 OPP 删除说明均含 `disabeld`，实际代码为 `disabled`；就近增加校对提示。中文短例全角 `；` 保留原文，不能直接当作有效 DTS 编译。
3. 英文 GPU leakage 说明使用 `rockchip, leak-voltage-sel`，代码及中文是 `rockchip,leakage-voltage-sel`；正文就近标明差异。代码注释中另外存在 `leakage-voltage-sell`，保留待核。
4. Clock 说明写 `clock`，代码使用 `clocks`；英文出现 `System-status-freq`、`Bus-supply` 大写，代码是小写；俄文明确指出，不改源代码。
5. §4.3.1 PLL 表的 `opp-1512000000` 与后续 `opp-1008000000` 之间看不到前一节点闭合 `};`，两份原稿如此；板级片段也含省略号或不完整结束分号。不擅自补结构，交付的是文档示例而非已编译 DTS。
6. §6.8 英文引用 §4.2.6（DMC IR-Drop），实际示例操作 GPU，GPU 对应 §4.1.6；保留原引用并记录。
7. 部分原稿代码注释说明值与实际配置不完全一致，例如修改后 IR-Drop 注释仍说 50000uV 而配置区间为 75000；各值与注释都原样保留，不作硬件操作依据。
8. 命令示例混有 C 风格注释，不是可直接粘贴执行的完整 shell 脚本。升频先升压、降频先降频再降压的源文警告完整保留；整理过程中未执行硬件写入命令。
9. 源产品表“所有芯片、Linux 4.4/4.19”不代表全部 ArmSoM 板卡可用。具体 SoC、PMIC/Regulator、时钟、OPP、电源域、PVTM、BSP/内核需逐板确认。文章标为平台参考，日志和 Vmin 结论是原厂示例，不是 ArmSoM 实测。
